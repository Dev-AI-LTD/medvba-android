# MEDVBA localization glossary (Batch 1)

Initial glossary for Authentication + Onboarding UI only. Do not expand until later batches.

| English | Romanian | Spanish | Usage note |
| --- | --- | --- | --- |
| MEDVBA | MEDVBA | MEDVBA | Brand — never translate or transliterate |
| Sign in | Autentificare | Iniciar sesión | Primary auth CTA / screen title |
| Sign up / Create account | Înregistrare / Creează cont | Registrarse / Crear cuenta | Prefer “Creează cont” / “Crear cuenta” for account-creation CTAs |
| Password | Parolă | Contraseña | Form labels and placeholders |
| Forgot password | Ai uitat parola? | ¿Olvidaste tu contraseña? | Keep question form when EN has `?` |
| Reset password | Resetare parolă | Restablecer contraseña | Prefer “restablecer” (ES) over “resetear” |
| Verify email | Verifică emailul | Revisa tu correo / Verifica el correo | Prefer “Revisa tu correo” when EN is “Check your email” |
| Continue | Continuă | Continuar | Generic CTA |
| Continue as guest | — | — | Not present in Batch 1 source strings |
| Offline | Offline / Fără internet | Sin conexión | Prefer “Fără internet” / “Sin conexión a internet” for connection-loss titles |
| Connection | Conexiune | Conexión | Used in offline / network copy |
| Retry | Încearcă din nou | Inténtalo de nuevo | Soft retry phrasing in error copy (no dedicated Retry key in Batch 1) |
| Anatomy | Anatomie | Anatomía | Only where Batch 1 onboarding/auth copy mentions it |
| Medical student | Student | Estudiante | Batch 1 uses “students” / “studenți” / “estudiantes”, not “medical student” |
