# App Store Keywords (MEDVBA)

Copy-paste into **App Store Connect** → app → locale → **Keywords** (max **100 characters**).

Use English commas with **no spaces after commas** to fit more terms.

---

## Where to paste (App Store Connect)

1. [App Store Connect](https://appstoreconnect.apple.com) → **MEDVBA**
2. **App Information** (or version **App Store** tab) → locale **English (U.S.)** or your primary language
3. Field **Keywords** → paste the EN line below (no spaces after commas) → **Save**
4. Optional: locale **Romanian** → paste the RO line → **Save**

---

## English (primary locale) — 88 characters

```
anatomy,medical,quiz,MCQ,exam,admission,study,physiology,pathology,neuroanatomy,AI,tutor
```

### Alternate EN — 92 characters

```
anatomy,medical,quiz,MCQ,exam,admission,study,physiology,neuroanatomy,medicalschool,AI,tutor
```

## Romanian (optional `ro` locale) — 86 characters

```
anatomie,medicina,quiz,admitere,examen,grila,fiziologie,neuroanatomie,studiu,tutor,UMF
```

Remove `UMF` if you prefer a fully generic Romanian keyword list.

---

## Do not include

- `live`, `Zoom`, `video`, `streaming`, `PiP`
- `MEDVBA` (app name is indexed separately)
- `Barron` / `Barrons` (third-party brand)
- `free`, `best`, competitor app names
